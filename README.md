# 虚数陨星采矿场

**虚数陨星采矿场（Imaginary Space Meteorite Excavation）为GTNH290版本的自动化坠星标位简化MOD。能够基于仪式物品直接生成对应产物，并且快捷地进行过滤，销毁不必要的垃圾。**

## 主要功能

- 直接根据坠星配方的期望产量获得矿石和填充方块物品。
- 支持通过本MOD的矿物过滤之书按仪式快捷过滤产物，销毁不必要的垃圾物品。

## 优势

- **机器占地空间小，且不需要实际生成巨大的陨星**：更加容易部署，且不会实际生成和破坏方块，对性能更友好。~~点名抨击某个只简化了召唤和采集，实则占地又大，陨星又碍事，搓个机器比搓自动化坠星还麻烦的塔斯汀~~。
- **简化了物品过滤，便捷舍弃无用产物：**提供了名为矿物过滤之书的物品，能够按照仪式分页自动获取仪式配方，点击对应产物可切换销毁和保留，机器产出结束时会按照书中对应配方直接舍弃被标记为销毁的物品。~~告别垃圾产物，告别sb的销毁用物流~~

## 游戏平衡性

- **合成**，从设计方便的角度，目前多方快结构是直接照搬GTNH采矿场II的结构的。主机也依旧需求血魔法和AE、IV材料的前置，整体造价和GTNH的采矿厂II差别不大，考虑到阶段平衡是没有问题的。

- **使用**，和TST的激光陨星采矿场一样采用无损超频，实际效率上也和T2的近似。考虑到造价和机器所处阶段问题，平衡是远比TST和原生弱的，**有追求的GT员工请谨慎选择使用**。~~但话又说回来了，为什么要和塔斯汀的弱智合成比，人家是大后期MOD，也不考虑你中期的使用问题~~
