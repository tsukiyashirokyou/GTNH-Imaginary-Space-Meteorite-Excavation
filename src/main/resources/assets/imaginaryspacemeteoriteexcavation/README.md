# Imaginary Space Meteorite Excavation resources

本 Mod 的资源命名空间为 `imaginaryspacemeteoriteexcavation`。

`lang/en_US.lang` 和 `lang/zh_CN.lang` 提供控制器、过滤书和三槽 GUI 文本。

`data/standard_meteors.json` 是从 GTNH 2.9.0 固定正式源码生成的 57 份标准坠星配置来源映射，带源文件 SHA-256；只用于识别和核对已注册配方，不注册或修改 Blood Magic 配方。

基础控制器复用 GT 采矿场 II 的稳定钛外壳及原生采矿面板纹理；过滤书暂用 Minecraft 原版书图标。没有复制或修改外部 Mod 的纹理。
